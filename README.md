# KROJ — versões

Instaladores do KROJ para Mac (Apple Silicon). Baixe o .dmg mais recente em **Releases**, abra e arraste o KROJ
para Aplicativos. Na primeira vez, abra com botão direito › Abrir.

O app procura atualizações sozinho (KROJ › Procurar Atualizações…) usando o `appcast.xml` deste repositório.
Seus livros ficam em Documentos/Livros KROJ e não são tocados pelas atualizações.
